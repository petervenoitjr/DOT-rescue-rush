# Music goes here

Put the AHAD music here as .mp3 files with these names (from `SETTINGS.audio.music`):

| File | Plays |
|---|---|
| `title.mp3` | title screen |
| `play.mp3` | in a sector |
| `alarm.mp3` | in an alarm sector (falls back to play) |
| `boss.mp3` | Crab Worker fight |

A missing track just stays quiet. Music is not packed into the sketch (too big):
keep this folder next to `dot_hex_page.html`, and in the p5 editor upload the files with the same names.
